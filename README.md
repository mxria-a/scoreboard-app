# 🏀 Dunkin' & Clunkin' Scoreboard

A simple basketball scoreboard built with HTML, CSS, and JavaScript. This project allows users to keep track of the home and guest team scores with buttons to add 1, 2, or 3 points and reset the game at any time.

## ✨ Features

* Track scores for both Home and Guest teams
* Add 1, 2, or 3 points with a single click
* Reset both scores with a **New Game** button
* Custom digital scoreboard styling using the Cursed Timer font
* Responsive, clean interface

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)
